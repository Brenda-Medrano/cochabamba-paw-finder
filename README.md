# Cochabamba Paw Finder

Quiero que generes un prototipo funcional y navegable de una plataforma web llamada FindMyPaw.

Objetivo del producto

FindMyPaw es una plataforma web para la ciudad de Cochabamba que ayuda a:

buscar mascotas perdidas,

reportar mascotas encontradas,

apoyar a los albergues para publicar perros en adopción.

La idea principal es centralizar la información para facilitar el reencuentro de mascotas con sus dueños y promover la adopción responsable.

Importante

NO incluir alertas inteligentes por zonas.

El prototipo no necesita backend real, pero sí debe verse funcional y navegable.

Debe ser amigable, limpio, intuitivo y responsive.

El idioma de toda la interfaz debe ser español.

El diseño debe inspirarse en una identidad visual cálida y amigable para mascotas.

Identidad visual

Usa estos colores como guía:

Morado oscuro: #2E235C

Violeta: #6D5CE8

Coral / naranja: #FF7A59

Amarillo claro / crema: #F3DE88

Blanco suave: #FFFDF6

Estilo:

amigable,

moderno,

limpio,

con bordes redondeados,

tarjetas visuales,

botones claros,

pensado para mascotas.

Estructura del prototipo

1. Landing page

Debe incluir:

logo de FindMyPaw,

nombre del producto,

eslogan: “Cada huella merece volver a casa”,

breve descripción:
“FindMyPaw es una plataforma para encontrar mascotas perdidas, reportar hallazgos y apoyar la adopción responsable en Cochabamba.”

botones principales:

Buscar mascota

Reportar pérdida

Reportar hallazgo

Adopta

Iniciar sesión

2. Pantalla de inicio de sesión / registro

Debe permitir:

iniciar sesión,

registrarse con nombre, correo y contraseña.

3. Pantalla de mascotas perdidas y encontradas

Debe incluir:

buscador por texto,

filtros por:

especie,

color,

zona,

fecha,

estado (perdido / encontrado),

listado en tarjetas con:

foto,

nombre,

especie,

fecha,

zona,

estado,

botón “Ver más”.

4. Pantalla detalle de mascota

Debe mostrar:

foto principal,

nombre,

descripción,

especie,

color,

tamaño,

fecha del reporte,

zona aproximada,

contacto protegido,

botón “Contactar”,

botón “Reportar avistamiento”.

5. Pantalla reportar mascota perdida

Formulario con:

nombre de la mascota,

especie,

raza opcional,

color,

tamaño,

fecha,

zona,

descripción,

foto,

contacto.
Botón: “Publicar reporte”.

6. Pantalla reportar mascota encontrada

Formulario con:

especie,

color,

tamaño,

fecha,

zona,

descripción,

foto,

contacto.
Botón: “Publicar hallazgo”.

7. Pantalla de adopciones

Debe mostrar perros disponibles para adopción en tarjetas con:

foto,

nombre,

edad aproximada,

tamaño,

nombre del albergue,

botón “Ver detalle”.

8. Pantalla detalle de adopción

Debe mostrar:

foto,

nombre,

edad,

tamaño,

estado de salud,

historia breve,

albergue responsable,

requisitos de adopción,

botón “Solicitar adopción”.

9. Pantalla formulario de adopción

Formulario con:

nombre,

teléfono,

tipo de vivienda,

experiencia con mascotas,

motivo de adopción.
Botón: “Enviar solicitud”.

10. Panel de albergue

Vista simple para:

ver perros publicados,

agregar perro en adopción,

revisar solicitudes recibidas.

Navegación

Crea una navegación superior con:

Inicio

Buscar

Reportar pérdida

Reportar hallazgo

Adopta

Iniciar sesión

Datos de ejemplo

Incluye datos ficticios realistas de mascotas y perros en adopción, con nombres, fotos de ejemplo, zonas de Cochabamba y textos simulados.

Experiencia de usuario

La interfaz debe ser sencilla de entender.

Debe ser usable por cualquier ciudadano.

Prioriza la claridad y facilidad de navegación.

Añade mensajes visuales de éxito en formularios.

Resultado esperado

Quiero un prototipo navegable y visualmente atractivo, ideal para validarlo con usuarios reales en una materia de Ingeniería de Software.
